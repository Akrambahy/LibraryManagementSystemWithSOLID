# Library Management System with SOLID

A simple Library Management System built with C# to practice SOLID principles.

## SOLID

* SRP — Single Responsibility Principle
* OCP — Open/Closed Principle
* LSP — Liskov Substitution Principle
* ISP — Interface Segregation Principle
* DIP — Dependency Inversion Principle

Also demonstrates **Dependency Injection** using constructor injection.

## Technologies

* C#

## Run

```bash
dotnet run
```
